  [1X1.1 [33X[0;0YOverview[133X[101X
  
  [33X[0;0YThis  package  identifies the groups of order dividing [22Xp^5[122X, for any prime [22Xp[122X,
  with  the  groups  in  the  SmallGroups  library  [BEO02], and it constructs
  isomorphisms onto the library groups. The algorithms are described in [DES].[133X
  
  [33X[0;0YThe   SmallGroups  library  contains  all  groups  of  order  [22Xp^5[122X,  but  its
  identification function [2XIdGroup[102X ([14Xsmallgrp: IdGroup[114X) is not available for the
  groups  of order [22Xp^5[122X with [22Xp ≥ 7[122X. After loading [5XIdp5[105X, [2XIdSmallGroup[102X ([14Xsmallgrp:
  IdSmallGroup[114X)  (equivalently  [2XIdGroup[102X  ([14Xsmallgrp:  IdGroup[114X))  works  for all
  groups  of  order  [22Xp^n[122X  with  [22Xn  ≤ 5[122X; see Section [14X2.1[114X. Moreover, the package
  provides  the  attribute  [2XIsomorphismSmallGroup[102X ([14X2.2-1[114X), which constructs an
  isomorphism    from    a    group    [22XG[122X    of   order   dividing   [22Xp^5[122X   onto
  [10XSmallGroup(IdSmallGroup(G))[110X.[133X
  
  [33X[0;0YThe  function [2XIdGroupsAvailable[102X ([14Xsmallgrp: IdGroupsAvailable[114X) is not changed
  by the package: for example, [10XIdGroupsAvailable(7^5)[110X still returns [9Xfalse[109X.[133X
  
  [33X[0;0YThe  identification  of  a  group  of  order  dividing  [22Xp^4[122X  also  yields an
  isomorphism  onto  the library group. The identification of a group of order
  [22Xp^5[122X  uses invariants, the identification of quotients of order dividing [22Xp^4[122X,
  and  linear algebra for the families of groups that depend on parameters. An
  isomorphism  from  a  group  of  order  [22Xp^5[122X  onto  the library group is then
  constructed  by  lifting  isomorphisms  between  quotients,  partly  with  a
  randomised search; see Section [14X2.2[114X.[133X
  
  [33X[0;0YThe randomised lifting algorithm for the isomorphisms of groups of order [22Xp^5[122X
  has  been  developed  with  the  LLM  Claude Opus; every isomorphism that it
  returns  is  verified.  The package files and this manual have been prepared
  with the assistance of Claude Opus.[133X
  
  
  [1X1.2 [33X[0;0YAn example[133X[101X
  
  [33X[0;0YWe   identify   a   randomly   generated  permutation  group  isomorphic  to
  [10XSmallGroup(7^5,65)[110X, and construct an isomorphism onto the library group.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27XR := SmallGroup(7^5, 65);;[127X[104X
    [4X[25Xgap>[125X [27XR := Image(IsomorphismPermGroup(R));;[127X[104X
    [4X[25Xgap>[125X [27Xrepeat gens := List([1..8], x -> Random(R)); until Group(gens) = R;[127X[104X
    [4X[25Xgap>[125X [27XR := Group(gens);;[127X[104X
    [4X[25Xgap>[125X [27XIdSmallGroup(R);[127X[104X
    [4X[28X[ 16807, 65 ][128X[104X
    [4X[25Xgap>[125X [27Xiso := IsomorphismSmallGroup(R);;[127X[104X
    [4X[25Xgap>[125X [27XSource(iso) = R;[127X[104X
    [4X[28Xtrue[128X[104X
    [4X[25Xgap>[125X [27XIdSmallGroup(Range(iso));[127X[104X
    [4X[28X[ 16807, 65 ][128X[104X
  [4X[32X[104X
  
  [33X[0;0YEach  call  of  [10XSmallGroup(7^5,65)[110X creates a new group, so [10XRange(iso)[110X is not
  equal  to  a group [10XH[110X constructed with [10XH := SmallGroup(7^5,65)[110X. However, both
  groups  are  given  by the same pc presentation, so mapping [10XPcgs(Range(iso))[110X
  onto [10XPcgs(H)[110X defines an isomorphism.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27XH := SmallGroup(7^5, 65);;[127X[104X
    [4X[25Xgap>[125X [27XisoRtoH := iso * GroupHomomorphismByImages(Range(iso), H,[127X[104X
    [4X[25X>[125X [27X                                  Pcgs(Range(iso)), Pcgs(H));;[127X[104X
    [4X[25Xgap>[125X [27XSource(isoRtoH) = R and Range(isoRtoH) = H and IsBijective(isoRtoH);[127X[104X
    [4X[28Xtrue[128X[104X
