1 Introduction

1.1 Overview

This package identifies the groups of order dividing p^5, for any prime p, with the groups in the SmallGroups library [BEO02], and it constructs isomorphisms onto the library groups. The algorithms are described in [DES].

The SmallGroups library contains all groups of order p^5, but its identification function IdGroup (smallgrp: IdGroup) is not available for the groups of order p^5 with p ≥ 7. After loading Idp5, IdSmallGroup (smallgrp: IdSmallGroup) (equivalently IdGroup (smallgrp: IdGroup)) works for all groups of order p^n with n ≤ 5; see Section 2.1. Moreover, the package provides the attribute IsomorphismSmallGroup (2.2-1), which constructs an isomorphism from a group G of order dividing p^5 onto SmallGroup(IdSmallGroup(G)).

The function IdGroupsAvailable (smallgrp: IdGroupsAvailable) is not changed by the package: for example, IdGroupsAvailable(7^5) still returns false.

The identification of a group of order dividing p^4 also yields an isomorphism onto the library group. The identification of a group of order p^5 uses invariants, the identification of quotients of order dividing p^4, and linear algebra for the families of groups that depend on parameters. An isomorphism from a group of order p^5 onto the library group is then constructed by lifting isomorphisms between quotients, partly with a randomised search; see Section 2.2.

The randomised lifting algorithm for the isomorphisms of groups of order p^5 has been developed with the LLM Claude Opus; every isomorphism that it returns is verified. The package files and this manual have been prepared with the assistance of Claude Opus.

1.2 An example

We identify a randomly generated permutation group isomorphic to SmallGroup(7^5,65), and construct an isomorphism onto the library group.

gap> R := SmallGroup(7^5, 65);;
gap> R := Image(IsomorphismPermGroup(R));;
gap> repeat gens := List([1..8], x -> Random(R)); until Group(gens) = R;
gap> R := Group(gens);;
gap> IdSmallGroup(R);
[ 16807, 65 ]
gap> iso := IsomorphismSmallGroup(R);;
gap> Source(iso) = R;
true
gap> IdSmallGroup(Range(iso));
[ 16807, 65 ]

Each call of SmallGroup(7^5,65) creates a new group, so Range(iso) is not equal to a group H constructed with H := SmallGroup(7^5,65). However, both groups are given by the same pc presentation, so mapping Pcgs(Range(iso)) onto Pcgs(H) defines an isomorphism.

gap> H := SmallGroup(7^5, 65);;
gap> isoRtoH := iso * GroupHomomorphismByImages(Range(iso), H,
>                                   Pcgs(Range(iso)), Pcgs(H));;
gap> Source(isoRtoH) = R and Range(isoRtoH) = H and IsBijective(isoRtoH);
true
